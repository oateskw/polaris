Drop royalty-free MP3 tracks in this folder to use them in your Reels.

Usage:
  polaris content reel-from-images img1.png img2.png --topic "..." --audio-file "trackname.mp3"

  You can pass just the filename (no path needed) if the file is in this folder:
  polaris content reel-from-images img1.png img2.png --topic "..." --audio-file "rise_up.mp3"

Good sources for royalty-free music:
  - https://pixabay.com/music/  (search "motivational", "upbeat business", "inspiring")
  - https://freemusicarchive.org
  - https://www.bensound.com  (free tier available)
  - https://incompetech.com   (Kevin MacLeod — Creative Commons)

Recommended search terms for business/entrepreneur Reels:
  - "corporate motivational"
  - "upbeat inspiring"
  - "success entrepreneur"
  - "business background"
